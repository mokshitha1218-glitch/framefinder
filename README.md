# FrameFind

FrameFind is a responsive image-discovery app where users will be able to search for images by topic. It uses a warm cream background and forest-green accents to create a calm, editorial visual identity. The large serif headline gives the interface a magazine-inspired layout. Quick-pick category chips and a dedicated empty state help visitors understand how to get started.

## Built with
- HTML
- CSS
- JavaScript

## Current version
